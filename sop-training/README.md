# Warehouse SOP Training

English/Urdu learning tool by Muhammad Naveed Bhatti. Three sample lessons cover receiving, stock count/reconciliation and controlled issue/returns. Each lesson has four procedure steps, a practice checklist and three knowledge-check questions. At least two correct answers pass. Previous completion is retained when later attempts fail; best and latest scores are exported separately.

Checklist completion is self-reported. Procedures are sample learning material, not organization-approved operating instructions or certification. Follow employer SOPs and authorization/safety requirements.

Select a video from your own recording studio to play it locally alongside a lesson. No upload occurs. Video selection is temporary and must be repeated on reload or lesson/language change. The browser must support the selected video format. Videos are optional for the sample lessons; no recording is bundled.

Progress is stored in localStorage when available; it is specific to the current browser and can be cleared or edited. CSV export provides a portable progress report. No account, server, paid API or dependencies. Open index.html locally or host on GitHub Pages. Language switches reset current checklist and answer inputs but keep saved completion results.
